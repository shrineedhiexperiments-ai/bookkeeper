How to get Zoho Books credentials
  1. Open api-console.zoho.com and create a Self Client. Copy its client ID and secret.
  2. Under Generate Code, use these scopes:
    ZohoBooks.bills.CREATE,ZohoBooks.bills.READ,ZohoBooks.contacts.CREATE,ZohoBooks.contacts.READ,ZohoBooks.accountants.READ,ZohoBooks.settings.READ
  3. Exchange the grant code for a refresh token within a few minutes:
    curl -X POST "https://accounts.zoho.com/oauth/v2/token?code=GRANT_CODE&client_id=ID&client_secret=SECRET&grant_type=authorization_code"
  4. Paste the client ID, secret, refresh token and organization ID above, save, then Test connection.
